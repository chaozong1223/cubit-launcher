启动按钮 · 6 种状态

按钮必须让用户随时知道「现在能不能点、点了会发生什么」。不可逆状态（安装中 / 启动中 / 运行中）用 spinner 或计时器表达；崩溃态用暖色而非整块红色，避免恐吓。

未安装 not-installed
版本文件缺失或损坏。点击进入安装；按钮不可用于启动。
就绪 ready
预检测通过。唯一主操作；点击后立即切换到启动中。
安装中 installing
补齐资源 / 安装加载器。显示阶段与进度；可取消，但不显示“启动”。
启动中 launching
参数已生成，等待进程。展示预检测 → Java → 参数 → 进程四个阶段。
运行中 running
只显示计时与「查看日志 / 结束游戏」；不重复提供启动入口。
崩溃 crashed
显示退出码与报告入口。文案「游戏异常退出」，不用「崩溃了！」。

任何时刻都要能看到总量、速度与剩余时间。暂停保留断点；校验失败自动重试；重试耗尽后仍给出可操作的「重试 / 换源」。

错误与提示文案

三句话结构：发生了什么（事实）→ 影响是什么（可选）→ 下一步能做什么（必须有）。技术错误码放在次要位置，不放进标题。禁止感叹号堆叠、禁止“未知错误，请联系管理员”。

不要这样写

启动失败：Error: spawn ENOENT
  • 只有原始异常，用户不知道发生了什么
  • 没有下一步，也没有“重试”入口
  • 英文技术词直接暴露在首屏

这样写

找不到 Java 21
这个实例需要 Java 21 才能启动。可以自动下载，或手动选择已安装的 Java。
  • 主操作：下载 Java 21
  • 次操作：选择已有的 Java
  • 详情折叠显示 JAVA.NOT_FOUND 与 traceId

不要这样写

游戏崩溃了！！！
请把截图发给我们。
  • 只描述情绪，不提供可执行信息
  • 要求截图而不是可复制的纯文本报告

这样写

游戏异常退出（返回码 1）
可能缺少前置模组 Flywheel。可以查看完整日志，或复制报告发给朋友。
  • 主操作：查看报告
  • 次操作：重新启动 / 打开日志
  • 置信度低时写“可能是…”，不武断下结论
语气与格式
中文、短句、不用「您」；一句话不超过 40 个汉字。可操作动词开头（查看 / 重试 / 选择 / 打开）。错误码、路径、traceId 用等宽字体放在详情里。Toast 最多两行，不放多个按钮。

关于这份设计原型
Cubit Launcher · 界面设计交付物 v0.1

这是一个单文件 HTML 原型：没有外部依赖，双击即可在浏览器中打开。所有按钮与状态都是静态演示，真实实现由 Electron IPC 提供数据，详见 design/README.md。
