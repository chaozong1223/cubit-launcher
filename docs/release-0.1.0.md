# Cubit Launcher 0.1.0

首个可分发的 Windows x64 绿色版。解压后直接运行 `mc-launcher.exe`（无需安装）。

> 未签名构建：首次运行 Windows SmartScreen 会拦截，点「更多信息 → 仍要运行」。

## 主要内容

**实例管理合并到主页**
- 实例列表、每行 `⋯` 菜单（概览/模组/资源包/光影/设置/导出/重命名/预览启动参数）、删除、筛选与折叠全部在主页
- 独立的「实例」页面已移除，旧链接自动落到主页

**游戏目录**
- 主页「游戏目录」区块：自动发现、选择、**在系统对话框里直接新建目录**、或使用已有 `.minecraft`

**资源库（Modrinth）**
- 模组 / 数据包 / 资源包 / 光影 / 整合包 五个独立分类，各自独立地址
- 项目详情是独立页面（`#/project/<id>`），版本按「加载器 + MC 版本」分组折叠，带 R/B/A 徽章
- 一键安装：模组装 `mods/`、数据包装 `datapacks/`、资源包装 `resourcepacks/`、光影装 `shaderpacks/`；整合包走导入流程创建新实例
- 项目图标来自 Modrinth CDN（CSP 已放行），无图标的项目显示彩色首字母

**安装与下载**
- 原版 / Forge / NeoForge / Fabric / Quilt
- 版本列表与原始 manifest 均可折叠；分类用「正式版 / 快照版 / 远古版本」
- 加载器安装器在**独立临时目录**内运行，避免 `%TEMP%` 权限问题导致 `AccessDeniedException`
- 镜像 host 白名单补入 `mirrors.qlu.edu.cn`，减少回落到慢速官方源

**回收站**
- 删除的实例留在**同盘隐藏目录**（`.mc-launcher-trash`），删除与恢复都是改名操作，不再跨盘复制十几 GB
- 支持永久删除，包括「冲突/不可恢复」的条目
- 截图页可在「移入回收站」与「永久删除」之间选择

**界面与交互**
- 全部下拉统一为自定义组件：向下展开、可输入筛选、点击外部或 Esc 收起
- 分页切换、实例切换、版本列表展开、分类切换均有过渡动画
- 外部链接与「打开文件夹」改走 explorer.exe，不再弹系统错误框
- 微软登录的 client_id 已内置，安装后开箱可登录（`MCL_MS_CLIENT_ID` 仍可覆盖）

## 已知限制

- 构建未签名
- 联机：EasyTier 侧车首次使用时会自动下载（SHA-256 校验），需要网络
- 整合包导入耗时取决于文件数量与网络
