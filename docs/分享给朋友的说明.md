给朋友的下载与使用说明（可直接复制转发）
==========================================

【下载】
电脑浏览器打开这个页面：
https://github.com/chaozong1223/cubit-launcher/releases/tag/v0.1.0

在页面下方的 Assets 里点这个文件下载（约 154 MB）：
mc-launcher-0.1.0-win-x64.zip

如果 GitHub 打不开或很慢，用加速工具（比如 Watt Toolkit 的「GitHub 加速」），
或者让我传你网盘 / 直接发文件。

【安装（其实是解压即用）】
1. 解压到一个你自己能记住的目录，例如 D:\Cubit
   —— 不要直接在压缩包里双击运行，也不要放 C:\Program Files。
2. 双击 mc-launcher.exe
3. Windows 可能提示「已保护你的电脑」（因为没做代码签名）：
   点「更多信息」→「仍要运行」。只第一次会提示。

【第一次打开要做的两件事】
1. 设置游戏目录：
   主页 → 实例与版本 → 游戏目录 → 管理游戏目录
   - 已经有 .minecraft 就点「选择目录」
   - 想新建就点「新建目录」，在弹窗里选位置、输入文件夹名
2. 选账户：
   账户页 → 微软正版选「开始微软登录」（不需要填任何应用 ID）；
   没有正版可以在那里建一个离线账户。

【装游戏】
主页点「新建实例」→ 选原版或加载器（Forge / NeoForge / Fabric / Quilt）
→ 选游戏版本 → 开始安装，等下载完。

【装模组】
资源库 → 选分类（模组 / 数据包 / 资源包 / 光影 / 整合包）
→ 搜索 → 点进项目 → 选版本 → 安装。
整合包会自动新建一个实例。

【注意】
- exe 旁边的 data 文件夹是账户和配置，别删。删了等于重新开始。
- 删实例 / 存档默认进回收站，能恢复；回收站里「永久删除」才是真删。
- 出问题把「日志」页的内容发我。
